## Figure 3: BLOS vs Av - Creation Script

You need to create this figure. Here's a Python script to generate it:

```python
import pandas as pd
import matplotlib.pyplot as plt
import numpy as np

# Read data
df = pd.read_csv('FileOutput/Perseus/FinalData/FinalBLOSResults.csv', sep='\t')

# Create figure
fig, ax = plt.subplots(figsize=(8, 6))

# Separate by sign
positive = df[df['Magnetic_Field(uG)'] > 0]
negative = df[df['Magnetic_Field(uG)'] < 0]

# Plot
ax.scatter(positive['Extinction'], positive['Magnetic_Field(uG)'].abs(),
           c='blue', alpha=0.6, s=30, label='Toward observer')
ax.scatter(negative['Extinction'], negative['Magnetic_Field(uG)'].abs(),
           c='red', alpha=0.6, s=30, label='Away from observer')

ax.set_xlabel(r'Visual Extinction $A_V$ (mag)', fontsize=12)
ax.set_ylabel(r'$|B_{\parallel}|$ ($\mu$G)', fontsize=12)
ax.set_xlim(0, df['Extinction'].max() * 1.1)
ax.set_ylim(0, df['Magnetic_Field(uG)'].abs().max() * 1.1)
ax.legend(loc='upper right', fontsize=10)
ax.grid(alpha=0.3)

plt.tight_layout()
plt.savefig('figures/BLOS_vs_Av.png', dpi=300)
plt.close()
```

## Notes

- **Distance discrepancy:** The paper intro says Perseus is at 294±17 pc (Zucker+ 2018), but the pipeline configuration uses 250 pc. You may want to update the config to match the paper, or update the paper to match the config, to avoid confusion.

- **Figure format:** PNG files are fine for the arXiv, but some journals prefer PDF/EPS for vector graphics. The pipeline generates PNG by default.

- **Color schemes:** The current BLOS map uses red/blue for away/toward, which is standard but may not be colorblind-friendly. Consider adding a note or using alternative colors if the journal requests it.
